Quantum computing is rapidly evolving from theoretical exploration toward practical applications. Among the most promising use cases are machine learning and data processing workloads, which fundamentally rely on vector and matrix computations. However, current high-level quantum compilers primarily support scalar integer arithmetic, leaving a significant gap in expressiveness for developers who wish to leverage quantum speedups for linear algebra operations.

\subsection{Related Work}
\label{sec:related}

QuantumC~\cite{quantumc} introduced an MLIR-based compilation pipeline that translates C programs with scalar integer operations into quantum circuits expressed in OpenQASM. While this approach successfully demonstrates the feasibility of high-level quantum compilation, it is limited to scalar arithmetic and does not support array or matrix operations.

Other approaches such as QHLS~\cite{qhls} explore high-level synthesis for quantum circuits but follow different architectural choices and do not leverage MLIR's multi-level representation capabilities.

\subsection{This Work}
\label{sec:thiswork}

In this work, we extend QuantumC to support vector and matrix operations while maintaining full compatibility with existing scalar code. Our extension introduces pattern-based recognition for common linear algebra operations---vector addition, dot product, and matrix multiplication---and integrates dedicated intermediate representations into the existing compilation pipeline.

The extended compiler supports hybrid programs that combine scalar and vector/matrix operations, as well as compile-time initialization of array data structures.

\subsection{Contributions}
\label{sec:contributions}

The main contributions of this paper are:

\begin{itemize}
    \item Pattern-based recognition of vector and matrix operations in C source code
    \item VecMat IR and QAR (Quantum Arithmetic Representation) intermediate representations
    \item Hybrid compilation supporting mixed scalar and vector/matrix programs
    \item Compile-time array initialization for vectors and matrices
    \item Comparative analysis of QFT-based and ripple-carry arithmetic backends using structural circuit metrics
\end{itemize}
